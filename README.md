## 📌 About

**OS Process Manager Simulator** is a Java-based project that simulates
basic operating system process management through an interactive CLI.

It demonstrates CPU scheduling, process states, memory management,
and core **OOP concepts** such as encapsulation, abstraction,
inheritance, and polymorphism.

## Features
- Create and manage processes
- Process states
- FCFS scheduling
- Priority scheduling
- Round Robin scheduling
- CPU simulation
- Memory allocation
- Process statistics

## Technologies
- Java
- OOP
- ArrayList
- Interfaces / Polymorphism

## OOP Concepts Used
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Composition
